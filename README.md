## QP Mutation

This applet implements Derksen-Weyman-Zelevinsky's mutation of quivers with potentials (<a href="https://arxiv.org/abs/0704.0649" target="_blank">arXiv:0704.0649</a>). 
This website is inspired by Keller's <a href="https://webusers.imj-prg.fr/~bernhard.keller/quivermutation/" target="_blank">quiver mutation applet</a>.

### Download and usage

You can use the applet directly on <a href="https://samueleblanc.com/software/qpmutation" target="_blank">samueleblanc.com/software/qpmutation</a>. 

If you want to download it, you can do the following. 
*Note that the latest version might be on the above website, but not yet on GitHub.* 

* Click on the latest version in the **Releases** section on the right of the screen.
* Click on ``QPMutation-vx.zip``.
* In your *Downloads* directory, you should see ``QPMutation-vx.zip``, which you can decompress (extract).
* In the new *QPMutation-vx* directory, double-click on ``index.html``.

N.B. If a text file opens, right-click on it and click on *Open with* [your favorite web browser].
